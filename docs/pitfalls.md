# Pitfalls we measured

Ten ways a recurring buy on Hedera fails that we hit or measured on testnet, and what in this template keeps each from happening. The finding links go to [testnet-findings.md](testnet-findings.md), which has the transactions and the numbers; the code links point at commit `26460f9`. Every contract test cited here has a twin in Solidity, `packages/foundry/test/RecurringBuy.t.sol`.
